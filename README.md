A [make.fun](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce) bounty entry: one single-line joke excusing a missed deadline.

## The line

> I didn't miss the deadline — I watched it march past my window like a parade I was supposed to be in.

## How it works

`main.ts` writes that one line — and nothing else — to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, falling back to a local `output/`), satisfying the competition gate of 1–200 characters of UTF-8 text.

## Run

```sh
node main.ts
```
